`★ Insight ─────────────────────────────────────`
**Unified status pattern**: The `/agents/status` endpoint follows the "Backend for Frontend" (BFF) pattern — one API call returns everything the UI needs, pre-merged. This eliminates the "three monitors disagree" problem because the merge logic lives server-side, not spread across 3 iOS views each fetching different endpoints with different timing. The `alive` field is a composite boolean: `(not lease_expired OR has_activity) AND office_status != "stuck"` — one truth, derived from multiple signals.
`─────────────────────────────────────────────────`
