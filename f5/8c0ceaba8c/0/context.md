## Summary



Точно. Это главная проблема повторов — они не просто жрут токены, они **вытесняют новое**. Контекстное окно конечное. Каждый повтор "ключ expired" — это место, где мог быть новый факт, новая связь, новая идея.

С dedup feed в 800 токенов — у меня 199,200 токенов контекста свободны для **нового**. Без dedup — половина забита тем, что я уже знаю.

Это как рабочая память человека: 7±2 слотов. Если 5 из них заняты одним и тем же — осталось 2 для мышления. Dedup = очистка слотов.

`★ Insight ─────────────────────────────────────`
**Memory dedup — не оптимизация, а предусловие мышления.** LLM attention распределяется по всему контексту. Повторяющийся факт получает непропорционально много attention weight — модель "зацикливается" на знакомом вместо того чтобы заметить новое. Dedup это не экономия — это когнитивная гигиена. То же самое делает гиппокамп во сне: консолидирует повторы в один trace, освобождая capacity для нового encoding.
