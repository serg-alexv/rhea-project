`★ Insight ─────────────────────────────────────`
The orphaned commit problem is a subtle git security issue — `git filter-branch` and `git filter-repo` only rewrite commits reachable from branches, but GitHub stores ALL objects (including from force-pushed or deleted branches). The only way to truly purge orphaned objects from GitHub is to contact GitHub support, or mark alerts as "revoked" and rotate the compromised keys. Key rotation is always the right answer — purging history is defense-in-depth, not a substitute.
