`★ Insight ─────────────────────────────────────`
**Naming collisions in flat Swift packages**: When all Swift files in a `.swiftpm/Sources` directory compile into one module, every top-level `struct` shares a single namespace. This is why `FilterChip` → `RadioFilterChip` and `AgentStatus` → `RadioAgentInfo` — the fix is prefixing with the view's domain. In a real multi-module project, Swift Package Manager's module boundaries handle this automatically.

**The iMessage alignment pattern**: `if isHuman { Spacer(minLength: 40) }` before content + the inverse after content is the standard SwiftUI technique for left/right chat bubble alignment. The `minLength: 40` ensures there's always a gap on the opposite side so bubbles never stretch full width.
