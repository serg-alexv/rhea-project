# Getting Started



Getting Started [#getting-started]

RheaKit is a Swift Package. The fastest route in is: add the package, set the backend base URL, boot the shared store, then mount the views you actually need.

Requirements [#requirements]

| Requirement | Version |
| ----------- | ------- |
| Swift       | 5.9+    |
| iOS         | 17.0+   |
| macOS       | 14.0+   |
| Xcode       | 15.0+   |

1\. Add the package [#1-add-the-package]

In your app's `Package.swift`, add RheaKit as a dependency:

```swift
// Package.swift
let package = Package(
    name: "MyApp",
    platforms: [.iOS(.v17), .macOS(.v14)],
    dependencies: [
        .package(path: "../packages/RheaKit"),
    ],
    targets: [
        .executableTarget(
            name: "MyApp",
            dependencies: ["RheaKit"]
        ),
    ]
)
```

If you prefer Xcode:

1. Open `File -> Add Package Dependencies...`
2. Point Xcode at the Rhea repository or the package folder
3. Select the branch or revision you want to ship against

2\. Confirm the backend target [#2-confirm-the-backend-target]

RheaKit automatically distinguishes between simulator and device:

| Runtime   | Default API URL                 |
| --------- | ------------------------------- |
| Simulator | `http://localhost:8400`         |
| Device    | `https://rhea-tribunal.fly.dev` |

You can override it with `UserDefaults`:

```swift
import RheaKit

UserDefaults.standard.set(
    "https://your-server.example.com",
    forKey: "apiBaseURL"
)
```

At launch, call:

```swift
AppConfig.migrateStaleDefaults()
```

That migrates older localhost values off physical devices so you do not strand a production build on an unreachable dev host.

3\. Start the shared state spine [#3-start-the-shared-state-spine]

`RheaStore` is the package nerve cord. It owns the core polling loop and recovery logic.

```swift
import SwiftUI
import RheaKit

@main
struct MyApp: App {
    init() {
        AppConfig.migrateStaleDefaults()
        RheaStore.shared.startPolling()
    }

    var body: some Scene {
        WindowGroup {
            ContentView()
        }
    }
}
```

The store polls `/agents/status` and `/health` every five seconds, then refreshes heavier SQL-backed surfaces on demand.

4\. Gate the app with auth [#4-gate-the-app-with-auth]

RheaKit uses `AuthManager.shared` for JWT state. A user can authenticate or skip, depending on your product policy.

```swift
import RheaKit

struct ContentView: View {
    @ObservedObject private var auth = AuthManager.shared

    var body: some View {
        if auth.isLoggedIn || auth.didSkipAuth {
            MainTabView()
        } else {
            AuthView()
        }
    }
}
```

`AuthView` already includes sign-in, sign-up, and Apple Sign In plumbing.

5\. Render the first control surfaces [#5-render-the-first-control-surfaces]

Every pane is self-contained. Drop the ones you need into a `TabView` or mount them individually.

```swift
import RheaKit

struct MainTabView: View {
    var body: some View {
        TabView {
            TeamChatView()
                .tabItem { Label("Radio", systemImage: "antenna.radiowaves.left.and.right") }

            GovernorView()
                .tabItem { Label("Governor", systemImage: "gauge.with.dots.needle.67percent") }

            TasksView()
                .tabItem { Label("Tasks", systemImage: "checklist") }

            BioRendererView()
                .tabItem { Label("Bio", systemImage: "atom") }

            SettingsView()
                .tabItem { Label("Settings", systemImage: "gear") }
        }
        .preferredColorScheme(.dark)
    }
}
```

6\. Use the package visual language [#6-use-the-package-visual-language]

Use `RheaTheme` tokens and `.glassCard()` for your own custom panes so they read as native Rhea surfaces.

```swift
import RheaKit

struct MyDashboard: View {
    var body: some View {
        VStack(alignment: .leading, spacing: 12) {
            Text("Status: Online")
                .foregroundStyle(RheaTheme.green)

            Text("Queries today: 42")
                .foregroundStyle(RheaTheme.accent)
        }
        .glassCard()
        .background(RheaTheme.bg)
    }
}
```
