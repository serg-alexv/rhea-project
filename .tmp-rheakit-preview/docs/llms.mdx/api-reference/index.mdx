# API Reference



API Reference [#api-reference]

This page documents the package spine first: the singletons, DTOs, and configuration surfaces most apps touch immediately.

For backend endpoint inspection, use the live OpenAPI surface at [rhea-tribunal.fly.dev/swagger](https://rhea-tribunal.fly.dev/swagger/).

Other exported surface types [#other-exported-surface-types]

| Type                  | Role                                           |
| --------------------- | ---------------------------------------------- |
| `SupervisorSession`   | Supervisor session identity and runtime status |
| `GovernorAgentStatus` | Pace, forecast, budget cap, and compliance     |

| `NDISource`           | Discoverable NDI source metadata               |
| `TaskItem`            | Task management row payload                    |
| `FeedItem`            | Team radio message payload                     |
| `ChatMsg`             | Dialog history message                         |
| `PipelineNode`        | Node editor graph node                         |
