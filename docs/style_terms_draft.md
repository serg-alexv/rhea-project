# Style Terms Draft

Use format:

`key=value; key=value; ...`

Valid keys:

- `обращение`: `по_имени` | `нейтрально` | `титул` | `<кастом_строка>`
- `дистанция`: `вплотную` | `близко` | `рабоче` | `формально`
- `прямота`: `0..5` (целое)
- `жесткость`: `0..5` (целое)
- `подкол`: `0..5` (целое)
- `сарказм`: `0..5` (целое)
- `флирт`: `0..5` (целое, может быть понижен safety-ограничениями)
- `теплота`: `0..5` (целое)
- `конфронтация`: `0..5` (целое)
- `мат`: `off` | `light` | `on` (без оскорблений/угроз)
- `длина`: `коротко` | `средне` | `подробно`
- `ритм`: `рублено` | `спокойно` | `живо`
- `эмодзи`: `off` | `low` | `medium`
- `стопы`: список через запятую (например `унижение,давление,explicit`)
- `красная_кнопка`: любое стоп-слово

Validation:

- Числа вне диапазона нормализуются в `0..5`.
- Неизвестные ключи игнорируются.
- Невалидные enum-значения заменяются безопасным значением по умолчанию.
