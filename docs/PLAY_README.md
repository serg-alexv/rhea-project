## One-Page Workflow

```
Design in Play
    ↓
Click Publish → Export to Xcode
    ↓
Choose: Project type, Framework (SwiftUI/UIKit), Assets
    ↓
Open in Xcode (Swift package)
    ↓
import PlayComponents
    ↓
Use: CardMedium() + .setText() + .setImage()
    ↓
Layer backend: API calls, database, auth
    ↓
Test: Preview, simulator, device
    ↓
Archive → App Store Connect → Submit
    ↓
Wait ~24-72 hours for Apple review
    ↓
Release to App Store
```

---

## Key Takeaway

Play to Xcode lets designers ship production iOS apps without writing UI code. No code generation—output is semantic Swift packages that blend seamlessly with custom Swift code.

**Perfect for:** MVP apps, designer-led teams, rapid prototyping  
**Not ideal for:** Backend-heavy apps, complex custom logic
