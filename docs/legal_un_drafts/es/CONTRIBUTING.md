# CONTRIBUTING (Borrador)

## 1) Alcance
Se aceptan contribuciones de código, docs, pruebas, UI, notas de investigación y tooling operativo.

## 2) Flujo de trabajo
- Fork/rama desde la rama principal.
- Mantener cambios enfocados.
- Agregar/actualizar tests cuando cambie el comportamiento.
- Abrir PR con resumen claro y notas de riesgo.

## 3) Sign-off (obligatorio)
Cada commit debe incluir firma DCO:

`Signed-off-by: Full Name <email@example.com>`

## 4) Licencia de contribuciones
Al contribuir, aceptas que tu aporte se licencia bajo la licencia del repositorio/ruta correspondiente y que tienes derecho a enviarlo.

## 5) Seguridad
No divulgar vulnerabilidades públicamente antes del fix coordinado. Usar el canal de seguridad.

## 6) Quality gates
Un PR puede bloquearse por tests/lint/licencias/provenance.
