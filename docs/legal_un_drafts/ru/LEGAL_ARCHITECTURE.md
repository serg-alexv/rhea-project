# LEGAL ARCHITECTURE (Черновик)

## 1) Назначение
Эта архитектура разделяет правовые режимы по типам артефактов, чтобы проект оставался открытым, переиспользуемым и управляемым как некоммерческий эксперимент.

## 2) Слойная модель
- Слой A — Open Core код: `Apache-2.0` (или `MIT` для отдельных модулей).
- Слой B — данные, контент, обучающие материалы: по умолчанию `CC BY-NC 4.0`, если не указано иное.
- Слой C — бренд-активы (названия, логотипы, визуальная идентичность): регулируются trademark policy.
- Слой D — хостинг и эксплуатация сервисов: регулируются Terms/Privacy/Security.

## 3) Базовые правила
- SPDX по умолчанию для кода репозитория: `Apache-2.0`.
- Примеры и документация: `CC BY 4.0`, если явно не отмечено как `CC BY-NC 4.0`.
- Лицензии сторонних зависимостей сохраняются и атрибутируются в `NOTICE` и манифестах.

## 4) Ограничители
- Никаких секретов в публичном репозитории.
- Нельзя перелицензировать сторонний код без прав.
- Каждый распространяемый артефакт должен иметь SPDX-идентификатор.
- CI обязан падать при нарушении лицензионной политики.

## 5) Связь с governance
Любые правовые изменения требуют:
- RFC issue,
- ревью мейнтейнеров,
- утверждения стюардов,
- записи в changelog правовых документов.

## 6) Дисклеймер
Документ является проектным черновиком и требует проверки профильным юристом до формального принятия.
