# CONTRIBUTING (Черновик)

## 1) Охват
Приветствуются вклады в код, документацию, тесты, UI, исследовательские заметки и операционные инструменты.

## 2) Workflow
- Форк/ветка от основной ветки.
- Делайте изменения узкими и целевыми.
- При изменении поведения добавляйте/обновляйте тесты.
- Открывайте PR с кратким summary и рисками.

## 3) Sign-off (обязательно)
Каждый commit должен содержать подпись DCO:

`Signed-off-by: Full Name <email@example.com>`

## 4) Лицензирование вкладов
Внося вклад, вы соглашаетесь, что он лицензируется по лицензии проекта/пути в репозитории, и что у вас есть право этот вклад передать.

## 5) Security
Не публикуйте уязвимости до согласованного исправления. Используйте security-канал проекта.

## 6) Контроль качества
PR может быть заблокирован из-за тестов, линтера, license checks или отсутствия provenance.
