# LICENSE MATRIX (Черновик)

## 1) Соответствие артефактов и лицензий
- Core source code: `Apache-2.0` (по умолчанию).
- Отдельные utility-модули: `MIT` (только при явной маркировке).
- Документация: `CC BY 4.0` (или `CC BY-NC 4.0` для ограниченных материалов).
- Исследовательские датасеты/контент: лицензия указывается в карточке датасета.
- Бренд, логотипы, названия: регулируются trademark policy, а не open source лицензией.

## 2) Разрешенные сторонние лицензии (базовый allowlist)
- `MIT`, `Apache-2.0`, `BSD-2-Clause`, `BSD-3-Clause`, `ISC`, `MPL-2.0`.

## 3) Ограниченные / требующие отдельного ревью
- `GPL-*`, `AGPL-*`, `LGPL-*`, `SSPL-*`, non-commercial или custom лицензии.
- Любая зависимость без явного SPDX-идентификатора.

## 4) Контроли соответствия
- Автоматический SPDX-скан в CI.
- Обязательное обновление `NOTICE` и атрибуций перед релизом.
- Нарушение policy-checks блокирует merge/release.

## 5) Исключения
Исключения по лицензиям требуют письменного согласования maintainer + steward и записи решения.
