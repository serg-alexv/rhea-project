# CONTRIBUTING (Brouillon)

## 1) Portée
Contributions bienvenues pour le code, la documentation, les tests, l’UI, les notes de recherche et l’outillage opérationnel.

## 2) Workflow
- Fork/branche depuis la branche principale.
- Conserver des changements ciblés.
- Ajouter/mettre à jour les tests quand le comportement change.
- Ouvrir une PR avec résumé clair et risques.

## 3) Sign-off (obligatoire)
Chaque commit doit contenir la signature DCO :

`Signed-off-by: Full Name <email@example.com>`

## 4) Licence des contributions
En contribuant, vous acceptez que votre contribution soit licenciée selon la licence du dépôt/chemin concerné et vous confirmez disposer des droits nécessaires.

## 5) Sécurité
Ne pas divulguer publiquement une vulnérabilité avant correction coordonnée. Utiliser le canal sécurité du projet.

## 6) Quality gates
Une PR peut être bloquée par tests/lint/licences/provenance.
