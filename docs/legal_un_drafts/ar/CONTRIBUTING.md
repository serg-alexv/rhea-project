# CONTRIBUTING (مسودة)

## 1) النطاق
نرحب بالمساهمات في الشفرة، الوثائق، الاختبارات، واجهة المستخدم، ملاحظات البحث، وأدوات التشغيل.

## 2) سير العمل
- Fork/فرع من الفرع الرئيسي.
- اجعل التغييرات مركزة ومحددة.
- أضف/حدّث الاختبارات عند تغيير السلوك.
- افتح PR بملخص واضح وملاحظات المخاطر.

## 3) التوقيع (إلزامي)
كل commit يجب أن يحتوي توقيع DCO:

`Signed-off-by: Full Name <email@example.com>`

## 4) ترخيص المساهمات
بالمساهمة، توافق على ترخيص مساهمتك وفق ترخيص المسار/المستودع المعني، وتؤكد امتلاكك الحق في تقديمها.

## 5) الأمن
لا تنشر الثغرات علنًا قبل الإصلاح المنسق. استخدم قناة الأمن الخاصة بالمشروع.

## 6) بوابات الجودة
يمكن حظر PR بسبب فشل الاختبارات أو lint أو فحوصات الترخيص أو نقص provenance.
