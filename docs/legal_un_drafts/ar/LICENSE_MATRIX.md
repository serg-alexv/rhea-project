# LICENSE MATRIX (مسودة)

## 1) ربط الأثر بالترخيص
- الشفرة الأساسية: `Apache-2.0`.
- وحدات أدوات محددة: `MIT` (عند وسم صريح فقط).
- الوثائق: `CC BY 4.0` (أو `CC BY-NC 4.0` للمواد المقيدة).
- مجموعات البيانات/المحتوى البحثي: الترخيص يحدد في بطاقة كل مجموعة.
- العلامة/الشعارات/الأسماء: تحكمها سياسة العلامة وليس ترخيص المصدر المفتوح.

## 2) تراخيص الطرف الثالث المسموح بها (القائمة الافتراضية)
- `MIT`, `Apache-2.0`, `BSD-2-Clause`, `BSD-3-Clause`, `ISC`, `MPL-2.0`.

## 3) تراخيص مقيدة / تتطلب مراجعة
- `GPL-*`, `AGPL-*`, `LGPL-*`, `SSPL-*`, والتراخيص غير التجارية أو المخصصة.
- أي تبعية بلا معرف SPDX واضح.

## 4) ضوابط الامتثال
- فحص SPDX آلي داخل CI.
- تحديث `NOTICE` ونسب الحقوق مطلوب قبل الإصدار.
- فشل السياسة يحجب الدمج/الإصدار.

## 5) الاستثناءات
الاستثناءات تتطلب موافقة مكتوبة من maintainer وsteward مع تسجيل القرار.
