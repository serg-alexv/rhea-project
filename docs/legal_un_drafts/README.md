# timelabs npo Legal Draft Pack (UN Languages)

This folder contains turnkey legal/governance drafts for the timelabs npo open experiment in all 6 official UN languages:

- Arabic (`ar`)
- Chinese (`zh`)
- English (`en`)
- French (`fr`)
- Russian (`ru`)
- Spanish (`es`)

Each language folder contains the same document set:

1. `LEGAL_ARCHITECTURE.md`
2. `GOVERNANCE.md`
3. `CONTRIBUTING.md`
4. `DCO.md`
5. `LICENSE_MATRIX.md`
6. `TRADEMARK_POLICY.md`

Status: draft set, intended for legal review and board approval.
