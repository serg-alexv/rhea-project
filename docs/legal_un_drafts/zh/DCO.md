# DEVELOPER CERTIFICATE OF ORIGIN（DCO）— 采用草案

本项目要求每个 commit 都带 DCO 签署。

## DCO 1.1 声明
我在向本项目提交贡献时声明：

(a) 该贡献全部或部分由我创建，且我有权按文件所示开源许可证提交；或

(b) 该贡献基于先前工作，且据我所知该工作受适当开源许可证覆盖，我有权在同一许可证下提交包含我修改的版本（除非另有许可）；或

(c) 该贡献由他人直接提供给我，且其已按 (a)/(b)/(c) 做出声明，我未对其进行修改。

(d) 我理解并同意：项目与贡献是公开的，贡献记录（含签署中的个人信息）将被长期保存。

## 如何签署
在每个 commit message 中添加：

`Signed-off-by: Full Name <email@example.com>`
