# CONTRIBUTING（草案）

## 1）范围
欢迎对代码、文档、测试、UI、研究笔记及运维工具进行贡献。

## 2）工作流
- 从主分支 fork/建分支。
- 保持改动聚焦。
- 行为变化时补充或更新测试。
- 提交 PR 时给出清晰摘要与风险说明。

## 3）签署（必需）
每个 commit 必须包含 DCO 签署：

`Signed-off-by: Full Name <email@example.com>`

## 4）贡献许可
提交即表示你同意按对应路径的项目许可证授权该贡献，并确认你有权提交。

## 5）安全
漏洞修复前不得公开披露；请走项目安全通道。

## 6）质量门禁
测试、lint、许可证检查或来源证明失败时，PR 可被阻止合并。
