# GOVERNANCE（草案）

## 1）使命
timelabs npo 将 Rhea 作为非商业开放实验运行，用于科学研究与公共利益场景。

## 2）角色
- Stewards：使命一致性、法律/伦理决策、最终升级处理。
- Maintainers：技术方向、发布决策、策略执行。
- Contributors：通过开放流程贡献代码/文档/研究。
- 社区：反馈、问题报告、公开评审。

## 3）决策流程
- 小改动：maintainers 共识。
- 大改动（架构/法律/策略）：RFC + 评审窗口 + stewards 批准。
- 安全紧急事件：可先处置，事后发布事件报告。

## 4）透明度
- 治理与策略决策公开变更记录。
- 重大事件与修复步骤公开披露。
- stewards 与 maintainers 需披露利益冲突。

## 5）行为规范
参与者须遵守项目行为规范与反骚扰规则；重复违规可被限制或移除。

## 6）修订规则
治理文件更新需 RFC 与 stewards 批准。
