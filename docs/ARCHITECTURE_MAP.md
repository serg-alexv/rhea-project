# Rhea Project - Architecture Map

## System Architecture

### Mobile Application Layer
- **ios/** - Primary iOS application
  - Swift/SwiftUI implementation
  - Extensions: Keyboard, Share, Tunnel
  - TailscaleKit integration for networking
  - App Store distribution

### Web Frontend Layer
- **frontend/** - Web-based interfaces
  - React/TypeScript applications
  - Community and dashboard interfaces
  - Static asset serving

### Command-Line Interface Layer
- **rhea-cli/** - Core CLI tools
  - Rust-based command-line applications
  - MultiTmux session management
  - API model wrapping

- **rhea-tui/** - Terminal user interface
  - Node.js terminal applications
  - Real-time system monitoring
  - Tokenometer integration

### Backend Services Layer
- **src/** - Core service implementations
  - Python-based services
  - Redis for state management
  - Firebase integration

- **rhea-session-server/** - Session management
  - User session persistence
  - Authentication state
  - Context continuity

- **rhea-rag/** - Retrieval-augmented generation
  - Document retrieval system
  - Context augmentation
  - AI response generation

### AI Integration Layer
- **rhea-ai-auth/** - Authentication and provider management
  - Rust-based authentication service
  - Multiple AI provider support
  - Secure credential management

- **rhea-ontology-explorer/** - Knowledge exploration
  - Ontology visualization
  - Semantic search
  - Knowledge graph navigation

### Data Persistence Layer
- **Redis** - Primary state storage
  - L1_hot: Active session state
  - L2_cold: Archive storage
  - Context window management

- **Firebase** - Cloud storage and sync
  - User data persistence
  - Real-time updates
  - Cross-device synchronization

### Deployment Infrastructure
- **deploy/** - Deployment configurations
  - Cloud Run services
  - Firebase hosting
  - Docker containerization
  - Build automation

### Development Tools
- **scripts/** - Build and deployment automation
- **tools/** - Development utilities
- **packages/** - Shared libraries
- **docs/** - Documentation

## Data Flow Architecture

1. **User Input** → Mobile/CLI/Web Interface
2. **Request Processing** → Backend Services
3. **Context Retrieval** → Redis/Firebase
4. **AI Processing** → RAG + AI Providers
5. **Response Generation** → Context + AI Output
6. **State Update** → Redis/Firebase
7. **Output Delivery** → User Interface

## Security Architecture

- **Authentication**: Multi-provider AI auth
- **Data Protection**: Encrypted storage and transit
- **Access Control**: Role-based permissions
- **Audit Trail**: Activity logging and monitoring

## Scalability Considerations

- **Horizontal Scaling**: Cloud Run services
- **State Management**: Redis clustering
- **Caching**: Multi-layer caching strategy
- **Load Balancing**: Automatic distribution
